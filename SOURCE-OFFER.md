GPL FlightGear aircraft (see `CREDITS-FlightGear.md`).

The complete corresponding source code (the web game, the Windows desktop shell, and the scripts
that convert the FlightGear AC3D/XML cockpit models into the shipped GLB files) is provided
alongside every binary release as `SkyRoutePro-0.1.0-source.zip`. The original FlightGear model
sources are available from the FGAddon repository: https://svn.code.sf.net/p/flightgear/fgaddon/trunk/Aircraft/
